# Afiliados Ofertas

Sistema pessoal para descoberta, filtragem e preparação de ofertas de afiliados.

## Objetivo da V1

- Integrar primeiro com a Shopee Affiliate Open API.
- Buscar produtos e ofertas.
- Filtrar ofertas por qualidade, desconto e avaliação.
- Evitar produtos repetidos.
- Gerar mensagem promocional padronizada.
- Preparar publicação em canal Telegram.
- Manter Mercado Livre como próxima integração.

## Segurança

Credenciais de afiliado nunca devem ser colocadas no código ou commitadas no GitHub. Use variáveis de ambiente.

## Status

V1 em construção. O projeto começa em modo de preparação/teste e só fará chamadas reais à Shopee depois que as credenciais oficiais da conta de afiliado forem configuradas.
